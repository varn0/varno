# Performance Baseline — 2026-10-18 (before optimization)

Captured on branch `feature/performance-optimization` at the start of implementation.

## Production bundle (`npm run build`)

```
dist/index.html                              2.40 kB │ gzip:  0.90 kB
dist/assets/profile-picture-*.jpeg          52.06 kB
dist/assets/index-*.css                     12.23 kB │ gzip:  3.00 kB
dist/assets/index-*.js                     257.04 kB │ gzip: 84.62 kB
68 modules transformed
```

**Key observation:** a **single** JS chunk (257.04 kB / 84.62 kB gzip) contains the entire app — `marked`, `react-router-dom`, and every route (`TechHome`, `CvPage`, `BlogIndex`, `BlogPost`, `ReadingPage`). Nothing is code-split. This is the "before" for Phase 3.1 (route splitting + `marked` isolation): the home entry chunk should shrink and `marked` + the lazy routes should appear as separate chunks.

## After (post-implementation)

```
dist/index.html                              2.68 kB │ gzip:  0.94 kB
dist/assets/profile-picture-*.jpeg          52.06 kB
dist/assets/index-*.css                     12.24 kB │ gzip:  3.01 kB
dist/assets/BlogIndex-*.js                   1.43 kB │ gzip:  0.66 kB
dist/assets/BlogPost-*.js                    2.17 kB │ gzip:  1.00 kB
dist/assets/ReadingPage-*.js                 5.39 kB │ gzip:  1.75 kB
dist/assets/CvPage-*.js                      8.38 kB │ gzip:  3.64 kB
dist/assets/marked-*.js                     41.73 kB │ gzip: 12.62 kB
dist/assets/index-*.js                     199.16 kB │ gzip: 66.31 kB
```

- **Home entry JS chunk:** 257.04 kB → **199.16 kB** (gzip 84.62 kB → **66.31 kB**, ~22% smaller). `marked` (12.62 kB gzip) and all four non-home routes are now separate chunks, loaded on navigation rather than on home first paint.
- **`/blog`:** `useBlogList` now issues exactly 1 `manifest.json` request, 0 per-post `.md` requests on index load (verified by `src/__tests__/hooks/useBlogList.test.tsx`). The serial fetch waterfall is gone.
- **Blog post bodies:** cached in-memory per session (`src/lib/fetchCache.ts`), so back-nav / re-open is a cache hit; also de-dupes the StrictMode double-fetch.
- **`/blog/modulith` diagram:** 454,042 B PNG → **109,656 B WebP** (75.85% smaller).
- **Icons:** self-hosting was DROPPED (no network in the build env — owner decision). Icons remain on `cdn.simpleicons.org` / `cdn.jsdelivr.net`; the `index.html` preconnect/dns-prefetch hints are the retained optimization.
- **Hero image:** explicit `width`/`height` + `fetchpriority="high"` (CLS + LCP priority). No resize/WebP (low payoff, out of scope).
- **Theme:** consolidated into one `ThemeProvider` context (removed duplicated per-component state).
